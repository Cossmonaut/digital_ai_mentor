Цель: Необходимо создать docker-compose, который позволит в отдельных контейнерах запустить основное приложение - telegram бота и его обвязку в виде БД neo4j и кеша redis.

Требования/Ограничения:

- Конфигурироваие всех элементов приложения должно быть реализовано через .env файл в корне директории
- docker compose должен лежать в корне проекта
- директории для монтирования должны располагаться в директории docker текущего проекта и не должны сохраняться в git
- В корне должны располанаться скрипты для запуска, остановки и обновления приложения
- Скрипт для старта должн проверять наличие уже запущенного приложения. Если приложение запущено, то просто выводить инфо в консоль о том, что оно уже работает, если нет, то запустить приложение

Критери приемки:

- Код должен корректно запускаться в docker без рестаротов и ошибок
- В корне проекта должны лежать docker-compose.yml, .env, start.sh, update.sh, stop.sh и больше нигде в директориях
- При запуске start.sh приложение запускается только если такового еще запущено в docker
- Все параметры запуска конфигурируются только через .env файл
- .env файл соответствует .env.example
